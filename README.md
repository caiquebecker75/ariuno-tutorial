# Ariuno · Tutorial para novas empresas

Apresentação em HTML para reunião de até 1 hora: como configurar a conta e colocar o time para trabalhar. Telas tiradas da demonstração do Ariuno, com dados fictícios.

Montar: `python3 fonte/montar.py`. Fotos: `node fonte/capturar.mjs <dist do Ariuno>`. PDF: `node fonte/gerar-pdf.mjs`.
